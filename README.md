**Acesse aqui**

🎯 **Objetivo do Projeto**

Desenvolver uma aplicação web educativa capaz de apresentar exercícios relacionados à linguagem C, permitindo a prática da lógica de programação e a compreensão dos conceitos fundamentais da área.

🧩 **Funcionalidades**

|O sistema apresenta as seguintes funcionalidades:|
|--|
📄 Exibição de exercícios em linguagem C
🧠 Organização lógica dos conteúdos
🖥️ Interface simples e acessível
📱 Navegação via navegador web
📚 Estrutura voltada ao aprendizado acadêmico
🎓 Apresentação organizada de conteúdos educacionais
🛠️ Tecnologias Utilizadas

|Este projeto foi desenvolvido utilizando:|
|--|
HTML5 — Estruturação das páginas
CSS3 — Estilização visual
JavaScript — Interatividade da interface
Linguagem C — Base dos exercícios apresentados
GitHub Pages — Hospedagem do projeto
Inteligência Artificial (IA) — Apoio na criação da estrutura e organização
